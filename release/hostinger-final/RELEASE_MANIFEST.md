## Release Folder

```text

```

This folder is a manifest and documentation entry point for the Hostinger deployment package.

A real ZIP archive was not created in this GitHub-only pass. To download a ZIP, use GitHub:

1. Open the repository.
2. Click Code.
3. Click Download ZIP.
4. Extract locally.
5. Remove files that should not be uploaded, such as `.git`, local logs, local `.env`, and private data.
6. Follow `release/HOSTINGER_DEPLOYMENT_GUIDE.md`.
