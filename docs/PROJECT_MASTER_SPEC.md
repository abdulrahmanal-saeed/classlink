# Project Master Spec
# المواصفة الرئيسية للمشروع

## Project Name / اسم المشروع

Habiba Nabil SaaS Platform

---

## Project Goal / هدف المشروع

Build a bilingual SaaS platform for Arabic learning that connects a PHP and MySQL web backend with a Flutter mobile app.

بناء منصة SaaS ثنائية اللغة لتعليم العربية، تربط بين موقع ويب مبني بـ PHP و MySQL وتطبيق موبايل مبني بـ Flutter.

---

## Main Users / المستخدمون الأساسيون

- Owner / مالك المنصة
- Admin / مدير النظام
- Teacher / المعلم
- Student / الطالب
- Parent / ولي الأمر
- Media Buyer / مسؤول الإعلانات
- Public visitor / زائر عام

---

## Core Modules / الوحدات الأساسية

- Authentication and roles / تسجيل الدخول والصلاحيات
- Student management / إدارة الطلاب
- Teacher dashboard / لوحة المعلم
- Homework system / نظام الواجبات
- Speaking scenarios / سيناريوهات التحدث
- Level tests / اختبارات المستوى
- Reviews and progress tracking / المراجعات وتتبع التقدم
- Notifications / الإشعارات
- Public landing pages / صفحات عامة وتسويقية
- Admin settings / إعدادات الإدارة
- Payments later / المدفوعات لاحقًا

---

## Language Requirements / متطلبات اللغة

- The platform must support Arabic and English.
- Arabic must be RTL.
- English must be LTR.
- Text should be managed through translation files when possible.

- المنصة لازم تدعم العربي والإنجليزي.
- العربي لازم يكون RTL.
- الإنجليزي لازم يكون LTR.
- النصوص يفضل تتدار من ملفات ترجمة كلما أمكن.

---

## Technical Requirements / المتطلبات التقنية

- Backend APIs in PHP.
- Database in MySQL.
- Mobile app in Flutter.
- Firebase only as supporting service.
- Clean folder structure by role and feature.
- Secure backend validation.
- Clear comments in important files.

---

## Build Philosophy / فلسفة البناء

Start simple, then expand.

ابدأ بسيط ثم وسع.

Every phase should produce a working part of the system.

كل مرحلة لازم تطلع جزء شغال من النظام.

Do not build too many features before the foundation is stable.

ما نبنيش فيتشرز كتير قبل ما الأساس يبقى مستقر.
