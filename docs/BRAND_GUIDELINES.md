# Brand Guidelines
# إرشادات الهوية البصرية

## Brand / البراند

Habiba Nabil Arabic Academy

منصة تعليم اللغة العربية للناطقين بغيرها، بأسلوب عملي، شخصي، واحترافي.

---

## Visual Direction / الاتجاه البصري

The product should feel:

- Warm
- Professional
- Clean
- Trustworthy
- Educational
- Not childish

المنتج لازم يكون إحساسه:

- دافئ
- احترافي
- نظيف
- موثوق
- تعليمي
- غير طفولي

---

## Logo Reference / مرجع اللوجو

The current visual reference is the Habiba Nabil Arabic Academy website.

المرجع الحالي هو موقع Habiba Nabil Arabic Academy.

Logo mark reference: Arabic letter ض

مرجع رمز اللوجو: حرف ض

## Language Direction / اتجاه اللغة

- Arabic: RTL
- English: LTR

- العربي: من اليمين إلى اليسار
- الإنجليزي: من اليسار إلى اليمين

---

## UI Style / شكل الواجهة

Use:

- Modern cards
- Rounded corners
- Soft shadows
- Clear buttons
- Friendly dashboards
- Clean spacing
- Clear status badges

استخدم:

- كروت حديثة
- حواف ناعمة
- ظلال خفيفة
- أزرار واضحة
- داشبورد مريحة
- مساحات نظيفة
- Badges واضحة للحالات

---

## Tone / نبرة المحتوى

The product copy should be:

- Clear
- Encouraging
- Professional
- Simple
- Friendly

نبرة الكلام تكون:

- واضحة
- مشجعة
- احترافية
- بسيطة
- ودودة
