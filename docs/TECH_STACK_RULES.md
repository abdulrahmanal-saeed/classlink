# Tech Stack Rules
# قواعد التقنيات المعتمدة

## Approved Stack / التقنيات المعتمدة

- Backend: PHP
- Database: MySQL
- Mobile App: Flutter
- Firebase: supporting service only when needed

---

## Arabic / عربي

أي كود أو برومت خاص بالمشروع لازم يلتزم بالتقنيات التالية:

- PHP للباك إند والـ APIs
- MySQL لقاعدة البيانات
- Flutter لتطبيق الموبايل
- Firebase كخدمة مساعدة فقط عند الحاجة

Firebase لا يستبدل PHP أو MySQL. هو يستخدم فقط في خدمات مساعدة مثل الإشعارات، التحليلات، Crashlytics، Remote Config، أو Auth إذا تم اختياره صراحة.

---

## English

Any project code or prompt must follow this stack:

- PHP for backend and APIs
- MySQL for database
- Flutter for mobile app
- Firebase only as a supporting service when needed

Firebase does not replace PHP or MySQL. It should only support services like notifications, analytics, Crashlytics, Remote Config, or Auth if intentionally selected.

---

## Rejected Unless Explicitly Requested / مرفوض إلا لو اتطلب صراحة

- Next.js
- Supabase
- Node.js
- MongoDB
- Prisma
- React Native
- Laravel

If any prompt includes one of these technologies, it must be rejected or converted back to the approved stack.

لو أي برومت فيه تقنية من دول، لازم نرفضها أو نحولها للستاك المعتمد.
