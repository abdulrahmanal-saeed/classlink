# Architecture and Folder Rules
# قواعد تنظيم الملفات والمعمارية

## 1. Main Rule / القاعدة الأساسية

The project must be organized by role and feature.

لازم المشروع يتقسم حسب الرول والفيتشر.

This helps us keep the code clean, scalable, and easy to maintain.

ده هيساعدنا نخلي الكود نضيف، قابل للتوسيع، وسهل التعديل.

---

كل رول يكون له فولدر مستقل.
